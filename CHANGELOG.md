# Changelog / Değişiklikler

## 0.1.0 — Unreleased / Henüz yayınlanmadı

### English

- Initial public-ready, dependency-free local screen-sharing tool.
- WebRTC video and automatic low-frame-rate JPEG fallback.
- Six-digit pairing, random receiver tokens, loopback-only sender controls, and request / origin checks.
- English and Turkish interface and documentation.
- Automatic private IPv4 selection and explicit adapter / address / port settings.
- Synthetic Chrome smoke tests, server tests, and a GitHub Actions workflow.
- MIT license, contribution and security policies, and GitHub publishing instructions.

No physical TV compatibility claim is included. Audio is not implemented.

### Türkçe

- İlk herkese açık paylaşıma hazır, bağımlılıksız yerel ekran paylaşım aracı.
- WebRTC görüntüsü ve otomatik düşük kare hızlı JPEG alternatifi.
- Altı haneli eşleştirme, rastgele alıcı anahtarları, loopback gönderici kontrolleri ve istek / kaynak doğrulaması.
- Türkçe ve İngilizce arayüz ile belgeler.
- Otomatik özel IPv4 seçimi ve adaptör / adres / port ayarları.
- Yapay görüntülü Chrome testleri, sunucu testleri ve GitHub Actions akışı.
- MIT lisansı, katkı ve güvenlik politikaları, GitHub yayınlama adımları.

Fiziksel TV uyumluluğu iddia edilmez. Ses aktarımı uygulanmamıştır.
